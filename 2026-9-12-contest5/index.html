T1

T3

给定一棵 nnn 个点的树，第 iii 个点有稳定亮度 mim_imi​ 与共振亮度 wiw_iwi​，外部中央调谐器接入编号为 kkk 的结点。每次启动给出直接作用半径 LLL，每个点必须从三种互斥模式中选择一种：恒稳模式，亮度为 mim_imi​；强共振模式，亮度为 wiw_iwi​，该模式合法当且仅当它至少有一个相邻点进入稳相核模式，或者它到接入点 kkk 的树上距离不超过 LLL；稳相核模式，亮度为 000，一个稳相核可以同时支持它的所有相邻点进入强共振模式，且没有容量限制。每次启动独立地重新选择全部点的模式，求该次启动中总亮度的最大值。共 qqq 次启动，每次给出一个 LiL_iLi​，分别输出答案。

数据范围：1≤n,q≤1051 \le n,q \le 10^51≤n,q≤105，0≤Li≤1050 \le L_i \le 10^50≤Li​≤105，1≤mi,wi≤1091 \le m_i,w_i \le 10^91≤mi​,wi​≤109，1≤k,u,v≤n1 \le k,u,v \le n1≤k,u,v≤n。

T4

有一块 RRR 行 CCC 列的显示屏，初始恰有 NNN 个互不相同的像素 (Si,Ei)(S_i,E_i)(Si​,Ei​) 已点亮，且至少还有一个像素未点亮。每一轮选择一个方向（上、下、左、右）向整块显示屏发送同一条复制指令：在本轮开始时已经点亮的每个像素，会使该方向上与它相邻的像素在下一轮开始时点亮，若相邻位置在显示屏之外则该次复制无效；已经点亮的像素保持点亮，本轮新点亮的像素不能在同一轮内继续复制。可以自行选择每一轮的方向，求使全部像素都点亮所需的最少轮数。

数据范围：1≤N≤3001 \le N \le 3001≤N≤300，1≤R,C≤1091 \le R,C \le 10^91≤R,C≤109，1≤Si≤R1 \le S_i \le R1≤Si​≤R，1≤Ei≤C1 \le E_i \le C1≤Ei​≤C，各 (Si,Ei)(S_i,E_i)(Si​,Ei​) 互不相同，且 N<R×CN<R \times CN<R×C。
